# Adam-Genesis-Claw

- Personal AI assistant gateway built on TypeScript/Node, supporting multi-channel messaging (Telegram, Discord, Slack, WhatsApp, iMessage, Signal, and more)
- Plugin architecture with a sandboxed extension system for custom providers, channels, and skills
- Self-hosted gateway model — runs on your own hardware with full control over data and routing
- Supports multiple AI model providers (Anthropic, OpenAI, and others) with a unified inference loop
- Includes voice, canvas rendering, mobile apps (iOS/Android), and a macOS menubar app

---

Based on [openclaw/openclaw](https://github.com/openclaw/openclaw).
