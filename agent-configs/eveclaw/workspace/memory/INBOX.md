# INBOX

Staging file. Eve appends items mid-session when she wants something remembered but can't update long-term memory in the moment. Jake can also write free-form entries here — notes, preferences, things to remember.

AdamClaw processes this file during curation runs and then clears it.

**Format:** `[YYYY-MM-DD source]` followed by the note. Source is either `Eve` or `Jake`.
